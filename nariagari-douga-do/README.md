# 成り上がり動画道

クソガキから世界一の動画配信者を目指す、連打＆放置のインクリメンタルゲーム。
`index.html` 1ファイルで動作します（外部画像・ライブラリ・ビルド不要）。
見出しと数字のフォントだけ Google Fonts（Dela Gothic One）を読み込みます。オフラインでも端末のフォントで遊べます。

## 遊び方

- 画面を連打 → 編集ゲージが満タンで動画を公開（マルチタッチ対応）。速く連打するとコンボ、100コンボでゾーン
- 企画会議：ネタ・やり方・サムネのカードを1枚ずつ選んで企画を作る。タグをそろえる・急上昇ジャンルのネタ・隠しレシピ（30種）で評価が上がり、C〜SSSの評価に応じてしばらく動画が伸びる
- 公開した動画は放置中も再生され続け、登録者とお金が増える
- 機材・スキル・スタッフを買うと、部屋に物や人が増えていく
- たまに飛んでくる「金のタネ」をタップするとボーナス
- キャラの上に吹き出しが出たら「できごと」。選び方しだいで得したり燃えたりする
- 炎上・著作権警告は連打で処理
- お金でコラボを依頼してコラボ相手を集める（図鑑30人、N / R / SR / SSR）
- ミッションを3つ同時進行。クリアで報酬
- 中堅クリエイターになったら引退（殿堂入り）できる。殿堂ポイントで永久強化してやり直し
- たまに「会心」タップで再生10倍。50・100・200…コンボごとにボーナス
- 動画を出すとチャンネルLvが上がって宝箱（銅・銀・金・虹）。虹は永久ボーナスつき。昇格でも宝箱
- まれに「超神回」で画面が虹色になり、伸びが10倍以上
- 登録者数で称号が昇格（全27称号）：クソガキ → 親のスマホ泥棒 → 無断転載 → パクリ常習犯 → 底辺YouTuber → … → 世界一のYouTuber(3億人) → … → 動画の神(1兆人)
- クリアまでの目安：約5時間（引退を使うと4時間半ほど）
- 進行は端末にも自動保存（最新・30秒ごとのバックアップ・いちばん進んだデータの3か所。メニューからデータを消せる）。オフライン中の再生も最大8時間ぶん受け取れる
- BGM・効果音はメニューで個別にON/OFF

## セーブコード（5桁）

- GAS で公開して遊ぶと、最初に5桁のセーブコードが1つだけ発行される。コードはずっと同じ
- 5分ごと・昇格したとき・画面を閉じたときに、そのコードへ自動で保存される（メニューの「今すぐ保存」でも保存できる）
- コードは画面右上とメニューにいつでも出ている
- ゲームが落ちて端末のデータが消えても、次に開いたときに「コードで続きから」が出る
- コードを忘れたら、GAS エディタで `listSaves` を実行すると、保存されている全コードが称号・最高登録者・最終保存時刻つきで表示される
- 別の端末やデータを消したあとは、メニューでコードを入れて「このコードで続きから」
- セーブデータは、スクリプトが自動で作るスプレッドシート「成り上がり動画道 セーブデータ」に入る
- 5桁なので、他人のコードを当てずっぽうで入れられる可能性はある。大事なデータではない前提で使う

## Google Apps Script で公開する手順

ゲーム本体（`index.html`）はブラウザが GitHub から直接読み込むので、GAS に貼るのは `Code.gs` だけ。ゲームを更新したときも貼り直しは不要。
（GAS は大きな HTML を約100KBで切ってしまい、スタートが押せなくなるため。GAS が返すのは小さな読み込み画面だけ）

1. [script.google.com](https://script.google.com) で新しいプロジェクトを作成
2. `コード.gs` の中身を `Code.gs` の内容で置き換える（`index` の HTML ファイルは作らなくてよい。前に作ったものは残っていても消してもよい）
3. 上の関数選択で **`setup`** を選んで「実行」→ 権限の確認が出たら許可（セーブ用スプレッドシートの作成）。実行ログに「準備OK」と出ればよい
4. 「デプロイ」→「新しいデプロイ」（すでにあるなら「デプロイを管理」→ 鉛筆 →「新バージョン」）→ 種類「ウェブアプリ」
   - 実行ユーザー: 自分
   - アクセスできるユーザー: 全員（または必要な範囲）
5. 発行された URL を iPad の Safari で開く（ホーム画面に追加すると全画面で遊べる）

ブラウザで `index.html` を直接開いても遊べます（その場合セーブコードは使えず、その端末だけに保存されます）。

`thumbnail_square.png` は正方形のサムネイル（1080×1080）、`thumbnail.png` は横長のサムネイル（1280×720）です。
