# 成り上がり動画道

クソガキから世界一の動画配信者を目指す、連打＆放置のインクリメンタルゲーム。
`index.html` 1ファイルで動作します（外部画像・ライブラリ・ビルド不要）。
見出しと数字のフォントだけ Google Fonts（Dela Gothic One）を読み込みます。オフラインでも端末のフォントで遊べます。

## 遊び方

- 画面を連打 → 編集ゲージが満タンで動画を公開（マルチタッチ対応）。速く連打するとコンボ、100コンボでゾーン
- 急上昇ジャンルと同じジャンルで投稿すると再生数ボーナス
- 公開した動画は放置中も再生され続け、登録者とお金が増える
- 機材・スキル・スタッフを買うと、部屋に物や人が増えていく
- たまに飛んでくる「金のタネ」をタップするとボーナス
- キャラの上に吹き出しが出たら「できごと」。選び方しだいで得したり燃えたりする
- 炎上・著作権警告は連打で処理
- お金でコラボを依頼してコラボ相手を集める（図鑑30人、N / R / SR / SSR）
- ミッションを3つ同時進行。クリアで報酬
- 中堅クリエイターになったら引退（殿堂入り）できる。殿堂ポイントで永久強化してやり直し
- 登録者数で称号が昇格：クソガキ → 無断転載(100人) → 底辺YouTuber(1,000人) → 中堅クリエイター(5万人) → トップYouTuber(100万人) → 世界一のYouTuber(3億人)
- 進行は localStorage に自動保存（メニューからデータを消せる）。オフライン中の再生も最大8時間ぶん受け取れる
- BGM・効果音はメニューで個別にON/OFF

## Google Apps Script で公開する手順

1. [script.google.com](https://script.google.com) で新しいプロジェクトを作成
2. `コード.gs` の中身を `Code.gs` の内容で置き換える
3. 「＋」→「HTML」で **`index`** という名前のファイルを作り、`index.html` の中身を貼り付ける
4. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 実行ユーザー: 自分
   - アクセスできるユーザー: 全員（または必要な範囲）
5. 発行された URL を iPad の Safari で開く（ホーム画面に追加すると全画面で遊べる）

ブラウザで `index.html` を直接開いても遊べます。
